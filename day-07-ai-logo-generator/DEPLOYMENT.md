# Deployment Guide — BrandCrafter.AI

## Prerequisites

- Node.js 18+
- Vercel CLI
- Google Gemini API Key

## Environment Variables

| Variable | Description |
|---|---|
| `GEMINI_API_KEY` | Optional: Google Gemini API key for dynamic brand synthesis |

## Deploy to Vercel

```bash
cd day-07-ai-logo-generator
npx vercel --prod
```

### Live URL
```
https://ai-logo-generator.vercel.app
```
