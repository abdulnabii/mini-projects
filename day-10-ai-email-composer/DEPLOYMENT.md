# Deployment Guide — EmailPulse.AI

## Prerequisites

- Node.js 18+
- Vercel CLI
- Google Gemini API Key

## Environment Variables

| Variable | Description |
|---|---|
| `GEMINI_API_KEY` | Optional: Google Gemini API key for dynamic email generation |

## Deploy to Vercel

```bash
cd day-10-ai-email-composer
npx vercel --prod
```

### Live URL
```
https://ai-email-composer.vercel.app
```
