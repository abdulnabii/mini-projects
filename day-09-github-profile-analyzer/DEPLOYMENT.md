# Deployment Guide — GitPulse.AI

## Prerequisites

- Node.js 18+
- Vercel CLI
- Google Gemini API Key

## Environment Variables

| Variable | Description |
|---|---|
| `GEMINI_API_KEY` | Optional: Google Gemini API key for dynamic persona synthesis |

## Deploy to Vercel

```bash
cd day-09-github-profile-analyzer
npx vercel --prod
```

### Live URL
```
https://github-profile-analyzer.vercel.app
```
