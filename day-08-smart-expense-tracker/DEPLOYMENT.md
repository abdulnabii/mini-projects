# Deployment Guide — ExpenseMind.AI

## Prerequisites

- Node.js 18+
- Vercel CLI
- Google Gemini API Key

## Environment Variables

| Variable | Description |
|---|---|
| `GEMINI_API_KEY` | Optional: Google Gemini API key for dynamic AI coach advice |

## Deploy to Vercel

```bash
cd day-08-smart-expense-tracker
npx vercel --prod
```

### Live URL
```
https://smart-expense-tracker.vercel.app
```
