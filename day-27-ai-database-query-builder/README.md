# QueryForge.AI — AI Database Query Builder & Visual Data Studio (Day 27)

> Translate plain English questions into production SQL queries, MongoDB aggregation pipelines, and Prisma/Drizzle ORM code with live execution sandbox, schema auto-inspection, index optimization suggestions, and auto-generated data charts.

## 🛠️ Features
- 💬 **Natural Language Query Builder**: Ask complex analytical questions in plain English.
- 🐘 **6 Multi-Dialect Engines**: PostgreSQL, MySQL, MongoDB Aggregation Pipelines, SQLite, Prisma ORM, and Drizzle ORM.
- ⚡ **Visual Schema Architecture Explorer**: 4 rich preset domain schemas (E-Commerce, Fintech Ledger, SaaS Billing, Healthcare) with table columns, PKs, and foreign keys.
- 📊 **Live Query Execution Sandbox**: Test queries with in-memory execution and latency metrics.
- 📈 **Auto-Generated Visual Charts**: Dynamically converts aggregate query outputs into interactive Bar charts and Metric cards.
- 🚀 **AI Index & Performance Optimizer**: Suggests exact `CREATE INDEX` statements with execution time improvements.
- 🗃️ **Saved Query Library**: Bookmark frequently used queries with 1-click clipboard copy.

## 🚀 Tech Stack
- **Framework**: Next.js 16 (App Router + Turbopack)
- **AI Intelligence**: Google Gemini 1.5 Flash
- **Styling**: Tailwind CSS v4 + Dark Obsidian Terminal Aesthetic
- **Icons**: Lucide React
- **Deployment**: Vercel Serverless
