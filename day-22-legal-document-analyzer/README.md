# ClauseWise.AI — AI-Powered Legal Document Analyzer & Contract Risk Intelligence

> **Day 22 of 30 Mini Projects**  
> Democratizing legal literacy with automated contract risk scoring, dangerous clause detection, plain-English translations, and Gemini 1.5 Pro document intelligence.

---

## 🌟 Key Features

1. **📄 Multi-Format Ingestion**: Drag & drop PDF/TXT/DOCX upload, raw contract paste zone, and 3 one-click benchmark scenarios.
2. **⚖️ 0–100 Risk Meter**: Animated circular gauge classifying contracts into SAFE, MODERATE, HIGH, or CRITICAL risk tiers.
3. **🚨 Dangerous Clause Highlighter**: Pinpoints severe, moderate, and mild clauses with exact quotes, plain-English breakdowns, and 1-click **Copy Counter-Proposal** wording.
4. **⚠️ Missing Protection Alerts**: Identifies standard missing safeguards (notice periods, IP carve-outs, liability caps).
5. **📑 Section-by-Section Accordion**: Grade 8 reading level explanations of every major contractual clause.
6. **💬 Grounded Document Q&A**: Ask Gemini targeted questions about severance, IP ownership, and restrictive covenants.
7. **🔀 Redline Version Diff Comparator**: Side-by-side comparison of original vs revised contract proposals.
8. **📥 Negotiation Brief Exporter**: 1-Click download of executive Markdown and PDF briefs for counter-negotiations.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (Turbopack) with App Router
- **Styling**: Tailwind CSS, Lucide React, Framer Motion
- **AI Engine**: Google Gemini 1.5 Pro & Gemini 1.5 Flash
- **Language**: TypeScript

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/abdulnabii/mini-projects.git
cd mini-projects/day-22-legal-document-analyzer

# Install dependencies
npm install

# Set environment variables (.env.local)
GEMINI_API_KEY=your_gemini_api_key_here

# Run development server
npm run dev
```
