## 💡 Overview

Intelligent resume architect with real-time ATS compatibility scoring, Google XYZ impact bullet rewriter, keyword gap analysis against target job descriptions, and print-ready PDF export.

---

## ✨ Key Features

- **Real-Time ATS Compatibility Gauge**: Evaluates keyword density, formatting compliance, and role suitability on a 0-100% scale.
- **Google XYZ Bullet Rewriter**: Transforms passive duty descriptions into high-impact quantified achievements (Accomplished [X], as measured by [Y], by doing [Z]).
- **Target Job Match Analyzer**: Paste any job description to discover missing hard/soft skills and high-value keywords.
- **Pixel-Perfect Print CSS**: Direct browser print styling producing immaculate single-page executive resumes.
- **Multi-Industry Role Presets**: One-click demo profiles for Software Engineers, Product Managers, and Data Scientists.

## 💻 Local Development Setup

Follow these steps to run **ResumeCraft.AI** locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abdulnabii/mini-projects.git
   cd mini-projects/day-03-smart-resume-builder
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment variables:**
   Create a `.env.local` file in the root of `day-03-smart-resume-builder`:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```
   *(Get your free API key from [Google AI Studio](https://aistudio.google.com/))*

4. **Start the local development server:**
   ```bash
   npm run dev
   ```

5. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to explore the application.

## 🚀 Production Deployment on Vercel

This project is pre-configured for instant zero-configuration deployment on **Vercel**:

1. Push your repository to GitHub.
2. Import the project into the [Vercel Dashboard](https://vercel.com).
3. Set the **Root Directory** to `day-03-smart-resume-builder`.
4. Add the `GEMINI_API_KEY` environment variable in Vercel settings.
5. Click **Deploy**!
