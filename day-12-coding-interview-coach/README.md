# AlgoCoach.AI — Real-Time AI Technical Interview Simulator

AlgoCoach.AI is a full-stack technical coding interview simulator that replicates the experience of a FAANG-grade technical interview.

## Key Features
- **AI Staff Engineer Interviewer (Alex)**: Presents problems, discusses approach, and responds dynamically.
- **Curated Problem Benchmarks**: Covers Arrays & Strings, Dynamic Programming, Graphs & Trees, and System Design across Easy, Medium, and Hard difficulties.
- **Progressive 3-Tier Hint Engine**: Request Tier 1 (Nudge), Tier 2 (Guidance), or Tier 3 (Pseudocode Blueprint) with score penalties.
- **Multi-Language Code Runner**: Supports Python, JavaScript, TypeScript, C++, and Java with test suite runners.
- **Post-Interview AI Assessment**: Evaluates Correctness, Code Quality, Communication, and Big-O Complexity ($O(N)$, $O(1)$) with side-by-side optimal solution walkthroughs.
- **LocalStorage Session History**: Tracks past interview scores and skill progression trends over time.

## Tech Stack
- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS & Lucide Icons
- Google Gemini API (`@google/generative-ai`)
- Vercel Production
