# RankCraft.AI — AI-Powered Blog SEO Optimizer & SERP Intelligence Platform

RankCraft.AI is a data-driven on-page SEO content auditor and AI rewriter that evaluates blog posts against search engine ranking signals.

## Key Features
- **8-Point Technical & Semantic SEO Audit**:
  - Overall SEO Health Score & Letter Grade ($0 \dots 100$, $A+ \dots F$).
  - Keyword Density & Distribution (Title, First 100 words, H1/H2, Body, Meta Description).
  - Flesch-Kincaid Readability Analysis (Reading Ease Score, Grade Level, Average Sentence Length).
  - Google SERP Snippet Preview (Desktop & Mobile live simulator).
  - Heading Structure Hierarchy Validator (H1 $\rightarrow$ H2 $\rightarrow$ H3 tree).
  - SERP Word Count Benchmark vs Top-10 Pages.
  - Semantic Internal Link Opportunity Detector.
  - GSC Organic Search Performance Simulator.
- **AI Section & Paragraph Rewriter (Gemini 1.5 Flash)**:
  - Generates on-demand paragraph rewrites to elevate Flesch ease, remove passive voice, and naturally position focus keywords.
  - Side-by-side Before/After diff viewer with readability gain badges ($+25$ points!).
- **Prioritized Action Plan Roadmap**:
  - Numbered improvement tasks sorted by SEO Impact (High/Medium/Low) vs. Effort.

## Tech Stack

- TypeScript
- Tailwind CSS & Lucide Icons
