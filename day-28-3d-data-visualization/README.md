# OmniData.3D — 3D Interactive Data Visualization Platform (Day 28)

> Transform structured CSV/JSON datasets into interactive 3D WebGL Earth globes, force-directed network graphs, animated 3D isometric bar matrices, and particle scatter plots with Gemini 1.5 Flash spatial storytelling.

![OmniData.3D Banner](https://raw.githubusercontent.com/abdulnabii/mini-projects/main/day-28-3d-data-visualization/public/preview.png)

## ⚡ Live Demo
**Production URL**: [https://day-28-3d-data-visualization.vercel.app](https://day-28-3d-data-visualization.vercel.app)

---

## 🛠️ Features
- 🌍 **3D Geospatial Earth Globe**: Interactive 3D Earth sphere with glowing geographic coordinate spikes and orbital flight arcs.
- 🕸️ **3D Force-Directed Network Graph**: Spatial node cluster with orbital physics and co-investment syndicate edges.
- 📊 **3D Isometric Voxel Bar Grid**: Multi-region cloud compute and revenue density surface elevation.
- ✨ **3D Particle Scatter Cloud**: Multi-axis spatial sensing particle cloud with harmonic orbital pulsing.
- 🤖 **Gemini 1.5 Flash Spatial Narrative Engine**: Automated anomaly detection, statistical pattern discovery, and multi-paragraph executive summaries.
- 🎥 **Canvas Video Recording & Snapshot Export**: 1-Click high-resolution PNG snapshot or 5-second rotating MP4/WebM video export.
- 🗃️ **Spatial Visualization Gallery**: Bookmark and revisit custom 3D plots.

---

## 🚀 Tech Stack
- **Framework**: Next.js 16 (App Router + Turbopack)
- **3D Graphics & Rendering**: Three.js + HTML5 WebGL Canvas
- **AI Spatial Intelligence**: Google Gemini 1.5 Flash
- **Styling**: Tailwind CSS v4 + Terminal Dark Aesthetic
- **Deployment**: Vercel Serverless
