# PromptCraft.AI — Advanced AI Prompt Engineering Terminal

PromptCraft.AI is a full-stack web terminal designed to transform unstructured user prompts into production-grade, model-tuned system instructions and engineered prompts.

## Key Features
- **Framework Model Tuning**: Targeted optimizations for Gemini 1.5, Claude 3.5 Sonnet, GPT-4o, and Midjourney v6.
- **5-Axis Prompt Quality Scorecard**: Scores clarity, context, constraints, formatting, and safety guardrails (0–100 rating).
- **3 Structural Output Variants**: Strict System Prompt, Chain-of-Thought Deep Reasoning, and High-Impact Persona Engine.
- **Dynamic Variable Extraction**: Auto-detects `{{variables}}` and builds an interactive form for parameter substitution.
- **Live Gemini Test Sandbox**: Run optimized prompts in real-time inside the browser.
- **Production Templates & Archives**: 6 industry-benchmark presets and local storage history.

## Tech Stack
- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS & Lucide Icons
- Google Gemini API (`@google/generative-ai`)
- Vercel Production
